# Status: deep-inference - 2026-06-27 14:30

## This month (north-star)
Build the torch-native package that does neural-network estimation AND hands back
valid influence-function confidence intervals, across many model families (13 GLMs,
multinomial, quantile, combinatorial, panel DiD) and economic targets (willingness
to pay, elasticity, welfare). The framework follows Farrell-Liang-Misra (2021, 2025).
The current month pivoted from internal coverage-validation toward positioning: a
full literature survey and a competitor map were just shipped, and the repo is now
choosing which new estimator family to build next.

## TLDR
The project is a software toolkit that lets a neural network estimate economic quantities
and, crucially, report honest error bars around them. This month the work shifted from
testing the existing tool toward looking outward: the team finished a survey of every
competing method out there and wrote up where this tool is genuinely different, which is
giving trustworthy error bars across both causal questions and economics-specific ones
like willingness to pay. The open question now is which new capability to build next, and
there is a ranked shortlist of five candidates with an early experiment already pointing at
the top one. One older task, fine-tuning the tool's accuracy in a hard simulation case, was
left half-finished and needs a decision on whether it is already good enough to stop. Worth
flagging: the written hand-off note from the last session is out of date and describes that
older task rather than the literature work that actually happened most recently.
